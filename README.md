# FocusTube

A Chrome extension that hides YouTube distractions (sidebar, comments, related videos, header) so you can focus on the video you're watching.

## Installation

1. Clone or download this repository
2. Go to `chrome://extensions`
3. Enable **Developer Mode** (toggle in the top right)
4. Click **Load Unpacked**
5. Select the `focustube/` folder
6. Pin the extension for easy access

## How to Use

- Open any YouTube video
- Press **Alt+Z** to toggle focus mode on/off
- Or click the extension icon and use the popup toggle
- Adjust the dim level using the slider in the popup

## Troubleshooting

- If **Alt+Z** doesn't work, check your shortcuts at `chrome://extensions/shortcuts`
- If elements still show after enabling focus, refresh the YouTube page once
- If the video looks unusual, disable and re-enable the extension
